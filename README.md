# 🚉 덕질역 — 버스·철도 덕질 커뮤니티

HTML·CSS·JS만으로 만든 커뮤니티형 사이트예요. 빌드 과정이 없어요.
**누구나 가입해서 글을 쓰고**, 활동하면 **포인트**가 쌓이고 **등급(노선도)** 이 올라가요. 포인트로 **테마·프로필 스킨·칭호**를 살 수 있어요.

## 기능 한눈에

| 구분 | 내용 |
|---|---|
| 글쓰기 | 가입한 **누구나** (공지사항은 운영진만, 등업신청은 KTX 조건을 채운 사람만) |
| 포인트 | 글 +20P(하루 3번, 30자 이상) · 댓글 +5P(하루 10번, 5자 이상) · 남의 글 공감 +1P(하루 20번) |
| 등급 | 🚇광역철도 → 🚃무궁화호 → 🚆새마을호 → 🚄KTX → 🛠부관리자 → 🛡관리자 → 👑총관리자 (아래 표) |
| 프로필 | 닉네임을 누르면 프로필. 등급 **노선도**와 다음 역까지 진행률 막대 |
| 상점 | 테마 · 프로필 스킨 · 칭호 (`#/shop`). 기차역·모노 화이트·야간 승강장 테마와 기본 스킨은 무료 |
| 테마 | **실제 기차역 안내판 스타일**(맨 위 노선색 띠 · 역 이름표 · 남색 간판 제목 · 모바일 아래 탭바). 무료 3종(기차역·모노 화이트·야간 승강장) + 노선 색 테마(1~9호선·KTX·공항철도·샌드 라운지·미드나잇·심야버스)는 포인트로 구매. 위쪽 🌙 버튼으로 밝게/어둡게 바로 전환하고, 처음 방문하면 기기의 다크 모드를 따라가요 |
| 편의 기능 | 키보드 단축키(`/` 검색 · `?` 도움말 · `g` 다음 `h/w/m/s/n` 이동 · `t` 맨 위 · `d` 밝게/어둡게) · 최근 본 글(홈) · 글쓰기 자동 임시 저장 · 탭 제목에 안 읽은 알림 수 · 글/쪽지 알림 · 아래쪽 탭바(모바일). 모두 `js/extras.js` 한 파일이라 빼도 사이트는 돌아가요 |
| 브라우저 알림 | 알림 화면·회원정보 수정의 "🔔 브라우저 알림"에서 켜요. 새 쪽지·댓글·공감을 브라우저 알림(푸시)으로 알려 줘요. 아래 "푸시 알림 설정" 참고 |
| 라이선스 | 글쓴이가 글 상단에 표시할 라이선스를 목록에서 고름 (CC BY 기본, CC BY-SA/NC/ND 조합, CC0, 모든 권리 보유) |
| 마크다운 | 글·댓글·사용자 문서에서 제목·굵게·기울임·취소선·코드·인용·목록·표·링크 지원 (HTML은 전부 무효 처리) |
| 사용자 문서 | 프로필에 표시되는 나만의 문서(위키처럼). `#/me/doc`에서 본인이 수정, 제목 3개 이상이면 목차 자동 생성 |
| 자동 로그인 | 로그인 창의 "자동 로그인" 체크(기본 켜짐). 끄면 브라우저를 닫았다 1분 넘게 지나 다시 열 때 로그아웃돼요 |
| 운영진 채팅 | 부관리자 이상이면 오른쪽 아래 💬 버튼으로 자동 참여(가입 절차 없음). 부관리자 아래로 내려가면 바로 사라져요. 3~12초마다 새 글을 확인하고, 30일 지난 대화는 자동 삭제돼요 |
| 문의·건의 | `#/inquiry` — 회원이 종류·제목·내용을 보내면(하루 5개) 운영진이 운영진 센터 "📮 문의/건의"에서 답변·상태 변경. 답변은 본인의 "내 문의 내역"에 보여요 |
| 프로필 사진 | 내 프로필의 "📷 프로필 사진 변경" — 가운데를 정사각형(256px)으로 잘라 작은 JPEG로 저장해요. 관리자급은 부적절한 사진을 지울 수 있어요 |
| 사진 확대 | 글·문서 안의 사진을 누르면 확대 보기(다시 누르면 확대/축소, Esc·바깥 클릭으로 닫기) |
| 검토 | 금칙어가 든 글·댓글은 "검토 대기" → 작성자와 운영진에게만 보임 → 운영진이 승인(포인트 지급)/삭제 |
| 운영진 센터 | `admin.html` — 대시보드, 글 관리, 검토 대기, 등업 신청, 회원(권한·포인트 지급), 상점 관리, 설정 |

### 등급 규칙

| 등급 | 조건 (모두 충족) | 등업 |
|---|---|---|
| 🚇 광역철도 | 가입 즉시 | - |
| 🚃 무궁화호 | 가입 1주 · 글 5 · 댓글 10 · 공감 10 | 자동 |
| 🚆 새마을호 | 가입 3주 · 글 20 · 댓글 50 · 공감 60 | 자동 |
| 🚄 KTX | 가입 8주 · 글 50 · 댓글 70 · 공감 100 | **등업신청 게시판에 글 → 운영진 승인** |
| 🛠 부관리자 | - | 관리자 이상이 회원 메뉴에서 지정 |
| 🛡 관리자 | - | 총관리자가 회원 메뉴에서 지정 |
| 👑 총관리자 | - | 처음 가입한 계정 |

주 수 기준(1/3/8주)·포인트 양·하루 한도는 `js/config.js`(그리고 DB의 `grade_rules`, `point_rules` 표)에서 고칠 수 있어요. 등급은 한 번 오르면 내려가지 않아요.

### 포인트·등급 직접 조정
관리자 센터 → 회원 → **💰 포인트·등급**. 포인트는 "증가/감소(-100처럼)" 또는 "이 값으로 지정"(0 미만은 불가), 등급은 원하는 등급으로 지정할 수 있어요. 등급을 직접 정하면 🔒가 붙어 자동 승급이 멈추고, "자동"을 고르면 활동 조건대로 다시 계산해요. KTX 등급은 여전히 등업 승인 방식이에요. 조정 내역은 회원의 포인트 내역에 남아요.

## 1단계: 바로 열어 보기 (로컬 데모 모드)

`js/config.js`의 `supabaseUrl`/`supabaseAnonKey`를 비우면 이 브라우저에만 저장되는 데모 모드로 열려요. 먼저 가입한 계정이 총관리자예요.

## 2단계: 진짜 사이트 (Supabase)

1. Supabase **SQL Editor**에 아래 파일을 **순서대로** 붙여 넣고 Run.
   1. `supabase/schema.sql` (처음 한 번 — 이미 실행했다면 건너뛰기)
   2. `supabase/v2_community.sql` ← **이번 업데이트** (관리자 역할·라이선스·사용자 문서·새 테마 포함, 여러 번 실행해도 안전해요)
   3. `supabase/storage.sql` (사진 올리기 — 이번에 정책이 "모든 회원"으로 바뀌었으니 다시 실행)
2. **이메일 인증 설정** (이메일 가입에 꼭 필요해요)
   1. **Authentication → Providers → Email → "Confirm email" 켜기** (이전엔 끄라고 했지만 이제는 **켜야** 해요)
   2. **Authentication → Providers → Email → "Secure email change" 끄기** — 켜져 있으면 예전 닉네임 회원(가짜 이메일)이 이메일을 등록할 때 옛 주소 확인이 필요해서 막혀요. 끄면 새 이메일 인증만 하면 돼요.
   3. **Authentication → URL Configuration**: **Site URL**을 `https://deokjil.xyz`로, **Redirect URLs**에 `https://deokjil.xyz/`를 추가 (메일 링크를 누르면 사이트로 돌아와요)
   4. (권장) **Project Settings → Authentication → SMTP Settings**에 직접 메일 서버(Gmail 앱 비밀번호, Resend 등)를 연결하세요. 기본 메일 서버는 시간당 발송 수가 아주 적어서(몇 통) 가입자가 몰리면 인증 메일이 막혀요.
   5. **인증번호 방식 메일 템플릿** — Authentication → Emails → Templates에서 아래 3개 템플릿의 **본문을 통째로** 바꾸고 Save (제목은 자유):
      - **Confirm signup** (제목 예: `[덕질역] 가입 인증번호`)
      - **Change Email Address** (제목 예: `[덕질역] 이메일 변경 인증번호`)
      - **Reset Password** (제목 예: `[덕질역] 비밀번호 재설정 인증번호`)

      ```html
      <h2>덕질역 인증번호</h2>
      <p>아래 인증번호를 사이트에 입력해 주세요. (잠시 후 만료돼요)</p>
      <p style="font-size:28px;font-weight:bold;letter-spacing:6px">{{ .Token }}</p>
      <p style="color:#888">본인이 요청하지 않았다면 이 메일은 무시해 주세요.</p>
      ```
3. `js/config.js`에 Project URL과 anon 키 입력 (`service_role` 키는 절대 X)
4. 폴더째 Netlify 등에 올리기.

### 기존 사이트를 업데이트할 때
- 기존 "글쓴이(author)" 권한은 자동으로 **부관리자**로 바뀌어요.
- 기존 글의 라이선스는 CC BY로 표시돼요(작성자가 글 수정에서 바꿀 수 있어요).
- 홈 소개 문구·흐르는 글은 DB에 저장된 값이 우선이라, 새 문구로 바꾸려면 관리자 센터 → 설정에서 고쳐 주세요.
- 기존 글은 모두 공개 상태로 유지돼요.
- SQL을 아직 안 돌렸다면 사이트 홈에 총관리자에게만 안내 문구가 떠요.

## 글쓰기 문법

- `# 큰 제목`, `## 작은 제목`, `**굵게**`, `*기울임*`, `~~취소선~~`, `` `코드` ``, `> 인용`, `- 목록`, `[글자](https://주소)`, `---`, 표(`| a | b |` 아래 `|---|---|`)
- 사진·유튜브 주소는 **한 줄에 붙여 넣기**
- **사진 올리기**: 버튼 / `Ctrl+V` / 끌어다 놓기 (긴 쪽 1600px로 자동 축소, 5MB 이하). `[img 50%]주소`로 크기 조절.
- 일반 회원 글의 **외부 사진 주소는 링크로만** 보여요(남의 사이트로 접속 정보가 새는 걸 막기 위해). 올리기로 올린 사진은 그대로 보여요.

## 서울교덕체 · 새 기능

- **서울교덕체 적용**: 글꼴 파일을 `fonts/` 폴더에 `SeoulGyodeok.woff2` / `.ttf` / `.otf` 이름으로 넣으면 사이트 전체에 자동 적용돼요. 파일이 없으면 기본 글꼴로 보여요. (방문자는 화면 맨 아래에서 전체 / 제목만 / 끄기, 글자 크기를 바꿀 수 있어요.)
- **서울교덕체 배포 페이지** `#/font`: 내려받기, 직접 써 보기(PNG 저장), 글자 모아보기, 웹사이트용 CSS 코드, 이용 안내. 이용 안내 문구는 `js/config.js`의 `font.license`에서 고쳐요.
- **출석부** `#/checkin`: 하루 한 번 5P, 연속 출석이면 하루에 1P씩 늘어 최대 11P.
- **내 스크랩** `#/bookmarks`: 글 아래 ☆ 스크랩 버튼. 나만 볼 수 있어요.
- **알림** `#/notifications`: 내 글에 댓글·공감, 내 댓글에 답글, 문의 답변이 오면 상단 🔔에 빨간 숫자로 알려줘요. 서버가 자동으로 만들어요.
- **쪽지** `#/messages`: 회원끼리 1:1 쪽지. 보낸 사람·받은 사람만 볼 수 있고 운영진도 못 봐요. 욕설 차단 (보내는 횟수 제한은 없어요. **30일이 지난 쪽지는 자동으로 삭제**돼요). 프로필의 "쪽지 보내기"로 시작해요.
- **운영진 휴게실** `admin.html#/lounge` (부관리자 이상): 미니게임 5종(카드 짝맞추기, 반응속도, 2048, 열차 뱀, 역 이름 타이핑)과 운영진끼리의 순위표.
- **운영진 회의실** `admin.html#/meetings`: 총관리자·관리자가 일정(제목·시간·안건)을 만들면 운영진에게 알림이 가요. 시작 10분 전부터 입장(출석)·채팅·투표를 할 수 있고, 끝난 뒤 한 시간까지 마무리 채팅이 돼요. 회의록은 관리자 이상이 써요.
- **맨 위로** 버튼, **홈 화면에 추가(PWA)** 지원.
- 업데이트할 때 `supabase/v2_community.sql`을 한 번 더 실행해 주세요 (출석·스크랩 테이블이 추가돼요).

## 보안 메모

- 포인트·등급·구매는 DB 함수(RPC)와 트리거가 계산해요. 브라우저에서 포인트나 등급을 직접 고칠 수 없어요.
- 글쓴이·작성 상태·댓글 닉네임은 서버가 정해요. 금칙어 검사도 서버(우회 표현 포함)에서 해요.
- 본문 렌더러는 HTML을 전부 이스케이프해요.
- 비밀번호 찾기는 없어요(이메일을 안 받아서).

## 가입 · 로그인 · 회원정보

- **가입**: 이메일 + 닉네임 + 비밀번호 → 메일로 온 **인증번호** 입력 → 가입 완료. 인증 전에는 로그인되지 않아요.
- **로그인**: 이메일로 로그인해요. (이메일 없이 예전에 닉네임으로 가입한 회원은 닉네임으로도 로그인돼요)
- **회원정보 수정** (`#/account`): 이메일 변경(새 이메일로 온 인증번호 입력)·비밀번호 변경(현재 비밀번호 확인). 예전 회원은 여기서 이메일을 등록할 수 있어요.
- **비밀번호 찾기**: 로그인 창 → "비밀번호를 잊었어요" → 이메일로 온 인증번호 + 새 비밀번호 입력.
- 데모 모드(Supabase 미연결)에서는 진짜 메일 대신 **인증번호가 화면에 표시**돼요. 비밀번호 찾기는 데모에서 쓸 수 없어요.

## 회원 강제 탈퇴 (관리자 이상)
관리자 센터 → 👥 회원 → 회원 줄의 **🚫 탈퇴** 버튼. 사유(5~500자)를 적으면 그 회원의 **가입 이메일로 사유가 전달**되고 계정이 삭제돼요. 기록은 같은 화면 아래에 남아요.
- 관리자(🛡)는 회원·부관리자만, 총관리자(👑)는 총관리자를 뺀 모두를 탈퇴시킬 수 있어요. 나 자신은 안 돼요.
- 삭제되는 것: 계정·댓글·쪽지·알림·포인트. 글은 남고 작성자 연결만 끊겨요.
- 예전 방식으로 가입해 진짜 이메일이 없는 회원은 메일 없이 탈퇴만 돼요(확인 창이 한 번 더 떠요).

### Supabase 쪽 준비 (처음 한 번)
1. SQL Editor에서 `supabase/v2_community.sql` 을 다시 실행 (탈퇴 기록 표 `member_removals` 가 생겨요. 여러 번 실행해도 안전해요).
2. **Edge Functions → Deploy a new function → Via Editor**, 이름 `remove-member`, `supabase/functions/remove-member/index.ts` 내용을 붙여넣고 Deploy. (JWT 검증은 켜 둔 그대로)
3. **Edge Functions → Secrets** 에 추가 (네이버 SMTP 값 그대로):
   `SMTP_USER` = 네이버 로그인 아이디 · `SMTP_PASS` = 비밀번호(2단계 인증이면 앱 비밀번호) · 선택: `SMTP_FROM`(기본은 SMTP_USER), `SITE_NAME`, `SITE_URL`
   (`SMTP_HOST` 기본 smtp.naver.com / `SMTP_PORT` 기본 465)
4. 관리자 계정으로 테스트 회원 하나를 만들어 탈퇴시켜 보고, 그 회원 이메일로 메일이 오는지 확인해 보세요.

## 운영 도구 · 내 노선도 (v4)
- **꼭 한 번**: Supabase SQL Editor에서 `supabase/v4_staff.sql` 을 실행해 주세요 (v3 다음에, 여러 번 실행해도 안전해요). 안 돌리면 정지·감사 로그·내 노선도가 "준비 중" 오류를 내요.
- **감사 로그** (관리자 이상, 운영진 센터 → 📜 감사 로그): 운영진이 남의 글·댓글을 지우거나, 신고를 처리하거나, 회원을 정지·해제하거나, 권한을 바꾸면 자동으로 남아요. 고치거나 지울 수 없고 CSV로 저장할 수 있어요.
- **회원 정지** (운영진 센터 → 회원 → ⛔ 정지): 1~365일 동안 글·댓글·쪽지·장터 글쓰기를 막아요(읽기·로그인은 돼요). 사유 필수, 본인에게 알림, 맨 위 안내 띠 표시, 나보다 높거나 같은 역할은 정지 불가. DB 트리거로 막아서 사이트를 거치지 않아도 소용없어요.
- **내 노선도** (`#/mymap`, 탭 3개, 나만 볼 수 있어요)
  - 🚇 노선 체크: 수도권·동남권·대구권·대전권·광주권 전철 노선을 눌러 안 탔어요 → 타 봤어요 → ★완주로 기록해요. 철도 열차는 **열차 종류(KTX·KTX-산천·KTX-이음·KTX-청룡·ITX…)를 누르면 그 열차의 노선**이 나와요 (KTX 계통은 코레일 운행계통 안내 기준). 가 본 역·타 본 버스도 직접 추가해요.
  - 🧭 이동 기록: 출발역 → 도착역, 탄 노선, **환승**(＋환승 추가, 최대 8구간)을 적어요. 탄 노선·역은 자동으로 체크돼요.
  - 🗺 내 지도: 지명·도로·강이 없는 **백지도**(시도 경계만) 위에 탄 구간을 **실제 선로 모양대로** 색 선으로 그려요. 타일 서버는 쓰지 않아요. 선로는 OpenStreetMap 데이터(`js/rails.js`, ODbL)에서 열차 종류(KTX는 고속선 우선, 일반열차는 일반선 우선)와 노선 이름(`config.js` 의 `routeOsm`)에 맞춰 `js/railroute.js` 가 최단 경로로 찾아요. 선을 못 찾은 구간은 긋지 않고 알려 줘요. 🧩 노선도 버튼으로 자동 배치 노선도(점 끌기·PNG 저장)도 볼 수 있어요. 지도 프로그램(Leaflet)·좌표·선로는 이 탭을 열 때만 불러와요. 버스 정류장은 안 찍어요.
  - 역 좌표는 `js/stations.js`(공공데이터: 전국도시철도역사정보 2026-06-30, 한국철도공사 철도역 위치 2024-04-01 + 동해역)에 들어 있어요. 새 역은 `["역이름",위도,경도]` 를 노선 id 아래에 더하고, 이름이 달라 못 찾을 땐 `alias` 에 `"쓰는이름":"파일의이름"` 을 더해요. 경계는 `js/korea-geo.js`(통계청 2018 시도 경계).
  - 방문자 IP는 내 지도를 열 때 cdnjs(Cloudflare)로 가요(Leaflet 내려받기). 개인정보처리방침에 적어 뒀어요.

## 푸시 알림 설정 (사이트를 닫아도 알림 받기)
설정을 안 해도 **덕질역이 열려 있는 동안**(다른 탭에 있어도)은 새 쪽지·알림이 브라우저 알림으로 떠요. 사이트를 닫은 뒤에도 받으려면 아래를 한 번 해 주세요. (주소가 **https** 여야 해요. 아이폰은 사파리에서 "홈 화면에 추가"한 앱에서만 돼요.)

1. **SQL**: `supabase/v2_community.sql` 을 다시 실행해요 (구독 표 `push_subscriptions` 와 함수 2개가 생겨요).
2. **VAPID 키 만들기** (내 컴퓨터에서 한 번): `npx web-push generate-vapid-keys` → 공개키/비공개키가 나와요.
3. `js/config.js` 의 `push: { vapidPublicKey: '…공개키…' }` 에 **공개키**를 넣어요.
4. **Edge Function**: Edge Functions → Deploy a new function → 이름 `push-notify`, `supabase/functions/push-notify/index.ts` 내용을 붙여넣고 Deploy. **Verify JWT 는 끄세요**(데이터베이스 웹훅이 부르기 때문에, 대신 아래 비밀 문자열로 막아요).
5. **Secrets**: `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `PUSH_WEBHOOK_SECRET`(아무 긴 문자열), 선택: `VAPID_SUBJECT`, `SITE_URL`(기본 https://deokjil.xyz)
6. **Database → Webhooks → Create**: 표 `notifications` · 이벤트 **Insert** · 종류 *HTTP Request* (POST) · 주소는 함수 주소 · 헤더 `x-push-secret: (위 비밀 문자열)`. 같은 방식으로 표 `dms` 도 하나 더 만들어요.
7. 사이트를 배포한 뒤 알림 화면에서 "알림 켜기"를 눌러 테스트해요.

참고: 쪽지 **내용은 알림에 담지 않아요**("○○님이 쪽지를 보냈어요"만). 구독이 끊긴 기기는 자동으로 지워져요. 한 사람당 기기 10개까지예요.
